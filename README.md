# Butano-Elementos
Trabalho Final do componente curricular Banco de Dados.
Projeto com objetivos educacionais, onde o usuario pode digitar o nome ou o simbolo de um elemento químico e ser exibido para o usuario o numero atomico, quantas ligações químicas ele faz, e a qual grupos quimico pertence.
Programação feita em HTML/CSS e PHP, com integração a banco de dados usando MySQL e o pocate do XAMPP PhpAdmin.
