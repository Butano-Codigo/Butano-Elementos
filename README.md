# Butano-Elementos
Trabalho Final do componente curricular Banco de Dados.
Projeto sobre (indefinido) para o usuario digitar o nome ou o simbolo de um elemento químico e ser exibido para o usuario o numero atomico, quantas ligações químicas faz, grupos quimicos, massa atomica, eletronegatividade , ponto de fusao e ponto de ebulição
